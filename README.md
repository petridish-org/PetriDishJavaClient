# PetriDish Java Client

**English** · [Русский](#petridish-java-client-1)

Official builds of the PetriDish client — a multiplayer cell-eating game.

**All downloads and platform links: [pc.petridish.pw](https://pc.petridish.pw)**

This repository hosts release binaries only — the game source code is not published here.
Every build is attached to a [release](https://github.com/petridish-org/PetriDishJavaClient/releases).

| Platform | File |
| --- | --- |
| Windows | `PetriDishJ<version>.exe` — no installer, just run it |
| macOS | `PetriDish-<version>-arm64.dmg` (Apple Silicon) / `-x64.dmg` (Intel) |
| Any desktop with Java | `PetriDish-desktop-min.jar` |
| Android 5.1+ sideload | `PetriDish-android-legacy-version.apk` |

Android and iOS are normally installed from
[Google Play](https://play.google.com/store/apps/details?id=pw.petridish) and the
[App Store](https://apps.apple.com/app/id1247567081).

The Windows build always available at the same address:
<https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDishJ.exe>

Game site: <https://petridish.pw>

# PetriDish Java Client

[English](#petridish-java-client) · **Русский**

Официальные сборки клиента PetriDish — многопользовательской игры про поедание клеток.

**Все загрузки и ссылки на платформы: [pc.petridish.pw](https://pc.petridish.pw)** — зеркало: **[pc.bact.io](https://pc.bact.io)**

Здесь лежат только готовые сборки — исходный код игры не публикуется.
Каждая сборка приложена к [релизу](https://github.com/petridish-org/PetriDishJavaClient/releases).

| Платформа | Файл |
| --- | --- |
| Windows | `PetriDishJ<версия>.exe` — без установки, просто запустить |
| macOS | `PetriDish-<версия>-arm64.dmg` (Apple Silicon) / `-x64.dmg` (Intel) |
| Любая система с Java | `PetriDish-desktop-min.jar` |
| Android 5.1+, установка вручную | `PetriDish-android-legacy-version.apk` |

Android и iOS обычно ставят из
[Google Play](https://play.google.com/store/apps/details?id=pw.petridish) и
[App Store](https://apps.apple.com/app/id1247567081).

Сборка для Windows всегда доступна по одному и тому же адресу:
<https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDishJ.exe>

Сайт игры: <https://petridish.pw>
