# PetriDish Java Client

**English** · [Русский](#petridish-java-client-1)

Official builds of the PetriDish client — a multiplayer cell-eating game.

**All downloads and platform links: [pc.petridish.pw](https://pc.petridish.pw)**

This repository hosts release binaries only — the game source code is not published here.
Every build is attached to a [release](https://github.com/petridish-org/PetriDishJavaClient/releases).

| Platform | Download |
| --- | --- |
| Windows | [`PetriDishJ.exe`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDishJ.exe) — no installer, just run it |
| macOS | [`PetriDish-<version>-arm64.dmg`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest) (Apple Silicon) or [`-x64.dmg`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest) (Intel) |
| Any desktop with Java | [`PetriDish-desktop-min.jar`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDish-desktop-min.jar) |
| Android 5.1+ sideload | [`PetriDish-android-legacy-version.apk`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDish-android-legacy-version.apk) |

Every link above always serves the newest release. The macOS file names carry the version
number, so those two lead to the [latest release](https://github.com/petridish-org/PetriDishJavaClient/releases/latest) page — pick the image for your Mac there.

Android and iOS are normally installed from
[Google Play](https://play.google.com/store/apps/details?id=pw.petridish) and the
[App Store](https://apps.apple.com/app/id1247567081).

Game site: <https://petridish.pw>

# PetriDish Java Client

[English](#petridish-java-client) · **Русский**

Официальные сборки клиента PetriDish — многопользовательской игры про поедание клеток.

**Все загрузки и ссылки на платформы: [pc.petridish.pw](https://pc.petridish.pw)** — зеркало: **[pc.bact.io](https://pc.bact.io)**

Здесь лежат только готовые сборки — исходный код игры не публикуется.
Каждая сборка приложена к [релизу](https://github.com/petridish-org/PetriDishJavaClient/releases).

| Платформа | Скачать |
| --- | --- |
| Windows | [`PetriDishJ.exe`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDishJ.exe) — без установки, просто запустить |
| macOS | [`PetriDish-<версия>-arm64.dmg`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest) (Apple Silicon) или [`-x64.dmg`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest) (Intel) |
| Любая система с Java | [`PetriDish-desktop-min.jar`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDish-desktop-min.jar) |
| Android 5.1+, установка вручную | [`PetriDish-android-legacy-version.apk`](https://github.com/petridish-org/PetriDishJavaClient/releases/latest/download/PetriDish-android-legacy-version.apk) |

Все ссылки выше всегда отдают самый новый релиз. В именах файлов macOS есть номер версии,
поэтому эти две ведут на страницу [последнего релиза](https://github.com/petridish-org/PetriDishJavaClient/releases/latest) — образ под свой Mac выбери там.

Android и iOS обычно ставят из
[Google Play](https://play.google.com/store/apps/details?id=pw.petridish) и
[App Store](https://apps.apple.com/app/id1247567081).

Сайт игры: <https://petridish.pw>
